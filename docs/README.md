- [Contratos de API](./contratos_api.md): Especificación REST, endpoints, formatos de respuesta y códigos HTTP.
- [Decisiones de Arquitectura](./decisiones.md): Registro de decisiones de diseño y tecnologías seleccionadas.
- [Especificación de Diseño y Vistas](./design/especificacion_vistas_y_flujos.md): Flujos de navegación, pantallas por tipo de usuario (Ciudadano y Recolector) y especificación de vistas faltantes.
